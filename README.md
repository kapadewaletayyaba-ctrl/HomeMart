## 📌 Project Overview

**HomeMart** is a comprehensive online furniture and home decor web application simulating a real-world shopping platform. Designed with a warm, inviting, and elegant visual aesthetic, it offers dynamic product browsing, category filtering, cart management, wishlist functionality, and a simulated checkout flow — all built entirely with client-side frontend technologies.

* **Domain:** E-Commerce (Furniture & Home Lifestyle)
* **Task ID:** `WD-EC-004`
* **Company:** Data Alcott Systems

---

## ✨ Features Implemented

### 📱 Core Features
- **Dynamic Single Page Architecture (SPA):** Seamless navigation across pages without full page reloads.
- **Category-Wise Product Showcase:** Filter products across Living Room, Bedroom, Dining & Kitchen, and Office & Decor.
- **Real-Time Search & Filtering:** Search items by name, filter by category, price range, and materials.
- **Interactive Shopping Cart:** Real-time quantity adjustments, subtotal calculation, free shipping threshold indicator, and side-drawer view.
- **Wishlist Support:** Quick toggle to save favorite furniture pieces with persistent feedback.
- **Product Quick View Modal:** Detailed preview modal featuring dynamic image selection, dimension breakdowns, material specs, and stock indicators.
- **Simulated Checkout Flow:** Multi-step order placement simulation including shipping address selection, payment option picker, and order summary.
- **User Authentication & Dashboard:** Simulated user sign-in/sign-up and profile dashboard showing order history and saved addresses.

### 🎨 Visual & UX Design Guidelines
- **Color Palette:** Warm Brown (`#8B6B4A`), Soft Cream (`#F5EDE6`), Warm Gold (`#D4A574`), and Deep Earth (`#3E2723`).
- **Typography:** Elegant serif headings paired with clean sans-serif body text (`Playfair Display` & `Inter`).
- **Responsiveness:** Fully responsive mobile-first layout styled with Tailwind CSS.
